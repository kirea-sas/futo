### Documentation informatique

Vireloq 3.2 — Notes d'installation

Avant d'installer Vireloq sur votre poste, vérifiez que l'environnement satisfait aux prérequis décrits ci-dessous. Le paquet a été compilé pour les distributions dérivées de Debian et pour macOS ; les utilisateurs de Windows passeront par la couche de compatibilité fournie séparément. Il faut qu'on insiste sur un point : l'installateur ne modifie jamais le fichier de configuration existant, il en dépose une copie suffixée à côté, et c'est à vous de fusionner les deux à la main.

La première chose à faire, c'est de créer un environnement virtuel dédié. On évite ainsi que les dépendances de Vireloq n'entrent en conflit avec celles d'un autre projet installé sur la même machine. Ouvrez un terminal et tapez :

    python3 -m venv ~/.local/venvs/vireloq
    source ~/.local/venvs/vireloq/bin/activate
    pip install --upgrade pip setuptools wheel
    pip install vireloq==3.2.1

Si la commande échoue avec un message évoquant une roue non compatible, c'est presque toujours que la version de Python est trop ancienne. Vireloq 3.2 exige Python 3.11 au minimum ; la version 3.13 est recommandée. Pour vérifier, faites `python3 --version` et comparez. Est-ce que vous voyez bien un numéro supérieur ou égal à 3.11 ? Si ce n'est pas le cas, installez une version plus récente avant d'aller plus loin.

L'étape suivante consiste à générer le squelette de configuration. Le binaire s'en charge tout seul :

    vireloq init --profil standard --dossier ~/Documents/vireloq
    cd ~/Documents/vireloq
    ls -la

Vous devriez voir apparaître trois fichiers : `vireloq.yaml`, `sources.json` et un dossier `sorties/` encore vide. Le premier contient les réglages généraux, le deuxième la liste des sources de données, le troisième accueillera les fichiers produits. Ne renommez pas le dossier `sorties/` : plusieurs scripts internes le cherchent à cet emplacement exact, et l'erreur qui en découle n'est franchement pas parlante.

Voici à quoi ressemble un fichier `vireloq.yaml` minimal, tel qu'il est écrit par la commande d'initialisation :

    version: 3
    projet:
      nom: "Inventaire régional"
      auteur: "Naïma Berthoud"
      langue: fr
    moteur:
      threads: 4
      memoire_max_mo: 2048
      cache: true
      chemin_cache: ~/.cache/vireloq
    sorties:
      format: parquet
      compression: zstd
      niveau: 9
    journal:
      niveau: info
      fichier: ./sorties/vireloq.log

Les clés sont en français par convention interne à l'entreprise Ombrelune SAS, mais rien ne vous empêche d'écrire les vôtres en anglais : l'analyseur accepte les deux jeux de noms, et il les normalise au chargement. En revanche, l'indentation doit être faite avec des espaces, jamais avec des tabulations ; c'est une contrainte du format YAML lui-même, pas un caprice de Vireloq.

Le fichier `sources.json`, lui, décrit d'où proviennent les données. Il s'agit d'un tableau d'objets, chacun devant comporter au minimum une clé `id` et une clé `url` :

    [
      {
        "id": "recensement-2024",
        "url": "https://donnees.ombrelune.example/recensement/2024.csv",
        "encodage": "utf-8",
        "separateur": ";",
        "actif": true
      },
      {
        "id": "cadastre-local",
        "url": "file:///var/lib/vireloq/cadastre.geojson",
        "encodage": "utf-8",
        "actif": false
      }
    ]

Remarquez que l'URL peut être locale : le schéma `file://` est accepté au même titre que `https://`. Les sources marquées `"actif": false` sont conservées dans le fichier mais ignorées à l'exécution ; c'est pratique quand on veut désactiver temporairement un flux sans perdre son paramétrage.

Guide de démarrage rapide

Une fois l'installation terminée, on peut lancer un premier traitement. La commande de base est `vireloq lancer`, à laquelle on passe le nom d'un profil. Voici l'enchaînement typique d'une première session :

    vireloq verifier --strict
    vireloq lancer --profil standard --limite 5000
    vireloq rapport --format html --sortie ./sorties/rapport.html

La commande `verifier` ne produit rien : elle relit la configuration, contacte chaque source active et signale les problèmes qu'elle rencontre. L'option `--strict` transforme les avertissements en erreurs, ce qui est très utile dans une chaîne d'intégration continue. La commande `lancer` fait le vrai travail ; l'option `--limite` restreint le nombre de lignes traitées, ce qu'on apprécie beaucoup quand on met au point une transformation sur un gros jeu de données.

Pour intégrer Vireloq dans vos propres scripts, il existe une interface Python. Elle est délibérément petite : trois classes et une poignée de fonctions. Voici un exemple complet, qui charge une source, filtre les enregistrements et écrit le résultat :

    from vireloq import Projet, Filtre

    projet = Projet.depuis_fichier("~/Documents/vireloq/vireloq.yaml")
    source = projet.source("recensement-2024")

    def est_valide(ligne: dict) -> bool:
        """Écarte les lignes dont l'âge est absent ou aberrant."""
        age = ligne.get("age")
        if age is None:
            return False
        return 0 <= age <= 120

    resultat = source.lire().filtrer(Filtre(est_valide))
    resultat.ecrire("./sorties/recensement_propre.parquet")
    print(f"{len(resultat)} lignes conservées sur {len(source)}")

Notez l'annotation de type sur le paramètre `ligne` : elle n'est pas obligatoire, mais l'outil de vérification interne s'en sert pour détecter les incohérences avant l'exécution. Notez aussi que `filtrer` renvoie un nouvel objet plutôt que de modifier celui d'origine ; toutes les opérations de Vireloq suivent ce principe, ce qui permet de les enchaîner sans crainte.

Côté navigateur, un petit client JavaScript permet d'interroger le serveur d'aperçu. Il ne dépend d'aucune bibliothèque externe et tient en quelques lignes :

    async function chargerApercu(identifiant, limite = 50) {
      const url = `http://localhost:8973/api/v1/apercu/${identifiant}?limite=${limite}`;
      const reponse = await fetch(url, {
        headers: { "Accept": "application/json" }
      });
      if (!reponse.ok) {
        throw new Error(`Réponse inattendue : ${reponse.status}`);
      }
      const donnees = await reponse.json();
      return donnees.lignes.map((l) => ({ ...l, _source: identifiant }));
    }

    chargerApercu("recensement-2024")
      .then((lignes) => console.table(lignes.slice(0, 10)))
      .catch((err) => console.error("Échec du chargement", err));

Le serveur d'aperçu n'écoute que sur l'interface locale, et il n'y a pas d'authentification : ne l'exposez jamais sur un réseau partagé. Si vous avez besoin d'un accès distant, passez par un tunnel chiffré, par exemple avec `ssh -L 8973:localhost:8973 utilisateur@serveur.example`.

Le format .glose expliqué

Vireloq écrit ses annotations dans un format maison portant l'extension `.glose`. Ce format a été conçu pour être lisible par un humain, modifiable dans n'importe quel éditeur de texte, et suffisamment strict pour qu'une machine puisse l'analyser sans ambiguïté. Il ressemble de loin à du YAML, mais il en diffère sur plusieurs points importants.

Un fichier `.glose` est une suite de blocs. Chaque bloc commence par une ligne d'en-tête introduite par un dièse suivi d'un espace, puis d'un identifiant. Viennent ensuite des lignes de propriété, de la forme `clé = valeur`, et éventuellement un corps de texte libre introduit par une ligne contenant uniquement trois tirets bas. Voici un bloc complet :

    # bloc-0017
    type = commentaire
    auteur = Émile Zarcanti
    date = 2026-03-14T09:42:00+01:00
    portee = lignes 240-268
    ___
    Cette section mériterait d'être réécrite. La boucle interne
    recalcule à chaque tour une valeur qui ne change jamais ;
    il suffirait de la sortir de la boucle pour gagner à peu près
    40 % de temps d'exécution sur les gros fichiers.

Les valeurs ne sont jamais entre guillemets : tout ce qui suit le signe égal, espaces de tête retirés, constitue la valeur. C'est un choix délibéré, qui évite les échappements pénibles mais interdit les valeurs multilignes en dehors du corps. Les dates suivent la norme ISO 8601 avec décalage horaire explicite ; l'analyseur refuse les dates naïves, celles qui n'indiquent pas de fuseau.

Un point qui surprend souvent : l'ordre des propriétés est significatif. Deux fichiers contenant les mêmes propriétés dans un ordre différent ne sont pas considérés comme identiques par l'outil de comparaison `vireloq diff`. Cela peut paraître pénible, mais c'est ce qui permet à l'outil de produire des différences minuscules quand on modifie un seul champ, plutôt que de réécrire le bloc entier.

Pour convertir un fichier `.glose` en JSON, utilisez :

    vireloq convertir --entree annotations.glose --sortie annotations.json --format json

Et dans l'autre sens, avec l'option `--vers-glose`. La conversion est réversible à condition de ne pas avoir de clés dupliquées dans le JSON de départ, puisque le format `.glose` les autoriserait alors que JSON les écraserait silencieusement. C'est le genre de subtilité qui coûte cher quand on s'en aperçoit trop tard.

Un message d'erreur commenté

Voici l'erreur la plus fréquemment signalée sur le forum d'entraide. Elle apparaît généralement au deuxième ou au troisième lancement, jamais au premier, ce qui la rend d'autant plus déroutante :

    Traceback (most recent call last):
      File "/usr/lib/vireloq/moteur/ordonnanceur.py", line 214, in resoudre
        empreinte = self._cache.empreinte(chemin)
      File "/usr/lib/vireloq/moteur/cache.py", line 88, in empreinte
        raise CacheDesynchronise(chemin, self.version_attendue, version_lue)
    vireloq.erreurs.CacheDesynchronise: le cache de ~/.cache/vireloq
    a été écrit par la version 3.1.4 mais la version courante est 3.2.1

Décortiquons. La dernière ligne dit l'essentiel : le dossier de cache contient des données produites par une version antérieure du logiciel, et le format interne a changé entre-temps. Vireloq refuse de lire un cache qu'il ne comprend pas plutôt que de risquer de produire des résultats faux — ce qui, avouons-le, vaut mieux. L'avant-dernière ligne indique où l'exception a été levée, et la ligne du dessus donne le chemin complet du fichier fautif, `/usr/lib/vireloq/moteur/cache.py`, à la ligne 88.

La correction est immédiate. Il suffit de vider le cache :

    rm -rf ~/.cache/vireloq
    vireloq lancer --profil standard

Le premier lancement suivant sera plus lent, forcément, puisque tout doit être recalculé. Sur un jeu de 1 234 567 enregistrements, comptez environ 2 h 30 sur une machine de bureau ordinaire, contre une quinzaine de minutes ensuite. Si vous voulez éviter le problème à l'avenir, ajoutez `purge_cache_au_changement_de_version: true` dans la section `moteur` de votre `vireloq.yaml` ; le nettoyage se fera alors automatiquement.

Une variante de cette erreur mentionne un code `EACCES` plutôt qu'une désynchronisation. Là, le diagnostic est différent : le processus n'a tout simplement pas le droit d'écrire dans le dossier indiqué. Cela arrive typiquement quand on a lancé une première fois Vireloq avec `sudo`, ce qui a créé les fichiers de cache au nom de l'utilisateur root. Vérifiez avec `ls -ld ~/.cache/vireloq` et rétablissez le propriétaire avec `sudo chown -R "$USER:$USER" ~/.cache/vireloq`. Et surtout, ne prenez pas l'habitude de lancer l'outil en tant que superutilisateur : il n'en a jamais besoin.

Enfin, un mot sur les journaux. Par défaut, le niveau est `info`, ce qui produit une ligne par étape. Pour un diagnostic sérieux, passez en `debug` :

    VIRELOQ_JOURNAL=debug vireloq lancer --profil standard 2>&1 | tee /tmp/vireloq-debug.txt

La variable d'environnement l'emporte sur le fichier de configuration. Le passage par `tee` conserve une copie du flux tout en l'affichant à l'écran, ce qui est commode quand on veut joindre le journal à un rapport de bogue. Déposez-le sur https://suivi.ombrelune.example/nouveau en précisant votre système d'exploitation, la version exacte du logiciel et, si possible, un fichier de configuration réduit qui reproduise le problème. Peut-être aurez-vous une réponse dès le lendemain : l'équipe est petite, mais elle lit tout.

### Scientifique et médical

Comment une cellule fabrique ses protéines

Tout part de l'ADN, cette longue molécule enroulée au cœur du noyau. On la décrit souvent comme un plan de construction, et l'image n'est pas mauvaise, à condition de préciser que le plan ne sort jamais de son classeur. La cellule en fait des copies partielles, appelées ARN messagers, et ce sont ces copies qui voyagent jusqu'aux ateliers, les ribosomes, où la protéine sera assemblée acide aminé par acide aminé.

Le mécanisme de copie est d'une régularité remarquable. Une enzyme, l'ARN polymérase, se fixe sur une région particulière de l'ADN et progresse le long du brin à la vitesse d'une cinquantaine de nucléotides par seconde. Elle lit, elle transcrit, elle avance. Si l'on ramenait la molécule à l'échelle d'un ruban de 1 mm de large, le noyau d'une cellule humaine mesurerait à peu près 4 m de diamètre et contiendrait près de 2 000 km de ruban plié. Il faut bien que quelque chose organise tout cela : ce sont les histones, des protéines autour desquelles l'ADN s'enroule comme du fil sur une bobine.

Une fois l'ARN messager formé, il subit une série de retouches. Des segments entiers en sont retirés — on les appelle des introns — et les morceaux restants sont recollés bout à bout. Ce découpage n'est pas toujours le même : selon les circonstances, la cellule peut assembler les morceaux différemment et produire, à partir d'un seul gène, plusieurs protéines distinctes. C'est l'une des raisons pour lesquelles le nombre de gènes humains, autour de 20 000, est bien inférieur à ce qu'on avait imaginé avant que le séquençage complet ne soit achevé.

L'assemblage proprement dit se déroule dans le ribosome, une machine moléculaire d'environ 25 nm de diamètre. Chaque triplet de bases lu sur l'ARN correspond à un acide aminé précis, et le ribosome ajoute ces acides aminés les uns aux autres, à raison de deux à vingt par seconde selon les organismes. Une protéine moyenne compte 300 à 400 acides aminés ; sa fabrication prend donc quelques dizaines de secondes. À la fin, la chaîne se replie sur elle-même en une forme tridimensionnelle très précise, et c'est cette forme, bien plus que la composition, qui détermine sa fonction.

Pourquoi le ciel est bleu, et pourquoi il ne l'est pas toujours

La lumière du Soleil nous paraît blanche, mais elle contient toutes les couleurs. Quand elle traverse l'atmosphère, elle rencontre des molécules d'azote et d'oxygène bien plus petites que sa longueur d'onde — quelques dixièmes de nanomètre contre 400 à 700 nm. Ces molécules dispersent la lumière dans toutes les directions, et elles le font d'autant plus efficacement que la longueur d'onde est courte. Le bleu, court, est dispersé environ cinq fois plus que le rouge. Voilà pourquoi, en levant les yeux vers une portion de ciel éloignée du Soleil, on reçoit surtout de la lumière bleue.

Au coucher du soleil, la géométrie change. Les rayons rasent l'atmosphère et parcourent une épaisseur d'air dix à quarante fois plus grande qu'à midi. Le bleu, dispersé très tôt sur ce long trajet, ne nous parvient plus ; il ne reste que les grandes longueurs d'onde, l'orange et le rouge. Est-ce que la poussière joue un rôle ? Oui, mais secondaire : elle accentue le phénomène et lui donne ses teintes les plus spectaculaires après une éruption volcanique, sans en être la cause.

Un détail amuse toujours les élèves : si la dispersion favorisait vraiment les longueurs d'onde les plus courtes, le ciel devrait être violet plutôt que bleu, puisque le violet est encore plus court. Deux raisons expliquent qu'il n'en soit rien. D'une part, le Soleil émet moins de violet que de bleu. D'autre part, notre œil est nettement moins sensible au violet. Le ciel est donc bleu autant par la physique de l'atmosphère que par la biologie de notre rétine.

L'intérêt d'un tel suivi tient moins à chaque mesure prise isolément qu'à la longueur de la série. On notera enfin l'ordre de grandeur des données : plus de douze millions d'observations pour quarante-deux points de mesure. Cela représente environ 480 Mo au format brut, réduits à 61 Mo une fois compressés. Les fichiers sont déposés en accès libre, sous licence ouverte, et l'article renvoie vers un dépôt public. C'est une pratique que l'OMS comme les grands organismes de recherche encouragent depuis des années, et qui progresse lentement mais sûrement.

Un mot sur l'imagerie

L'IRM, l'imagerie par résonance magnétique, repose sur un principe qui n'a rien d'intuitif. On place le patient dans un champ magnétique intense, entre 1,5 et 3 teslas pour les appareils cliniques courants — soit trente mille à soixante mille fois le champ magnétique terrestre. Les noyaux d'hydrogène du corps, extrêmement nombreux puisque nous sommes faits d'eau pour environ 60 %, s'alignent alors partiellement sur ce champ. Une brève impulsion radio les fait basculer ; en revenant à leur position initiale, ils émettent un signal que l'appareil capte et localise.

Ce qui distingue les tissus, ce n'est pas la quantité d'hydrogène mais la vitesse à laquelle ce retour s'effectue. Un tissu graisseux, un muscle et un liquide céphalorachidien se comportent différemment, et c'est ce contraste-là que le radiologue interprète. L'examen ne produit aucun rayonnement ionisant, contrairement au scanner ; en revanche, il est bruyant, long — de 20 à 45 min selon la région explorée — et strictement incompatible avec certains implants métalliques. La question posée systématiquement avant l'examen, « portez-vous un stimulateur cardiaque ou une prothèse métallique ? », n'est pas une formalité administrative.

Sur la manière dont les gens parlent

Ce qui frappe, quand on transcrit fidèlement une conversation ordinaire, c'est à quel point elle diffère de ce qu'on croit dire. Les phrases sont rarement achevées. On commence une idée, on l'abandonne, on la reprend trois répliques plus loin comme si de rien n'était. Les négations perdent leur premier terme presque systématiquement : on dit « je sais pas », « j'ai pas vu », « c'est pas grave », et le « ne » ne réapparaît qu'à l'écrit ou dans les registres soutenus.

Les pronoms se contractent aussi. « Il » devient « i' » devant consonne, « tu as » devient « t'as », « il y a » se réduit à « y'a » et parfois à un simple « ya » que l'oreille perçoit à peine. Le « nous » a pratiquement disparu au profit de « on », y compris chez des locuteurs qui, interrogés, jureraient dire « nous ». Et pourtant, le sens passe. La compréhension ne souffre d'aucune de ces réductions, parce que le contexte, l'intonation et le regard font le reste du travail.

Il y a enfin les mots qui ne veulent rien dire et qui servent à tout : « quoi » en fin de phrase, « hein » qui demande confirmation, « bon » qui annonce une transition, « bah » et « ben » qui marquent l'évidence ou l'embarras. On les qualifie parfois de parasites, ce qui est injuste. Retirez-les d'une transcription et l'échange devient étrangement raide, presque hostile. Ils sont le liant de la conversation ; qu'on les supprime et tout se met à sonner faux.

### Recettes de cuisine

Gratin de courgettes au chèvre frais — pour 4 personnes

Ingrédients : 900 g de courgettes fermes, 150 g de chèvre frais, 2 œufs, 20 cl de crème liquide entière, 1 gousse d'ail, 3 cuillerées à soupe d'huile d'olive, ½ cuillerée à café de thym séché, sel, poivre du moulin, 40 g de parmesan râpé.

Préchauffez le four à 190 °C, chaleur tournante. Lavez les courgettes, ôtez les deux extrémités mais gardez la peau : c'est elle qui tient le légume à la cuisson et qui apporte la couleur. Coupez-les en rondelles d'environ ½ cm d'épaisseur. Ne cherchez pas la régularité parfaite, mais évitez tout de même les écarts trop importants, sinon les tranches fines seront desséchées quand les épaisses seront encore crues.

Faites chauffer l'huile dans une grande poêle. Quand elle frémit, jetez-y les rondelles en deux ou trois fournées — surtout pas toutes d'un coup, sinon elles rendent leur eau et bouillent au lieu de dorer. Salez légèrement, poivrez, et laissez colorer 5 à 6 min de chaque côté. Réservez au fur et à mesure dans une passoire posée sur un saladier : le jus qui s'écoule aurait détrempé le gratin.

Pendant ce temps, préparez l'appareil. Battez les œufs dans un bol, ajoutez la crème, l'ail écrasé, le thym, une bonne pincée de sel et deux tours de moulin. Émiettez le chèvre du bout des doigts et incorporez-le sans chercher à le dissoudre : il faut qu'il reste des morceaux, ce sont eux qui feront les poches fondantes du plat fini.

Huilez un plat à gratin. Disposez la moitié des courgettes, versez la moitié de l'appareil, recommencez. Parsemez de parmesan. Enfournez pour 30 à 35 min : la surface doit être bien dorée et le centre à peine tremblant. Laissez reposer 10 min hors du four avant de servir, sinon le gratin s'effondre à la découpe. Il se réchauffe très bien le lendemain, à 150 °C pendant un quart d'heure.

Soupe de lentilles corail au lait de coco — pour 6 bols

Ingrédients : 300 g de lentilles corail, 1 gros oignon, 2 carottes, 1 morceau de gingembre frais de 3 cm, 1 cuillerée à café de curcuma, ½ cuillerée à café de cumin moulu, 1 litre de bouillon de légumes, 20 cl de lait de coco, le jus d'un ½ citron vert, 2 cuillerées à soupe d'huile neutre, sel.

Rincez les lentilles à l'eau froide jusqu'à ce que l'eau ressorte claire ; comptez trois ou quatre changements d'eau. Cette étape n'est pas facultative : elle retire l'amidon de surface qui rendrait la soupe pâteuse. Égouttez et réservez.

Épluchez l'oignon et hachez-le finement. Pelez les carottes et coupez-les en petits dés de ½ cm — plus ils sont petits, plus la cuisson sera rapide et homogène. Râpez le gingembre au-dessus d'une assiette pour ne rien perdre du jus.

Faites chauffer l'huile dans une cocotte à fond épais. Faites-y suer l'oignon 4 min à feu moyen, sans le laisser prendre couleur. Ajoutez les carottes, le gingembre, le curcuma et le cumin, et remuez pendant 1 min : les épices doivent chauffer dans le gras, c'est ce qui libère leurs arômes. Versez ensuite les lentilles, mélangez, puis mouillez avec le bouillon chaud.

Portez à ébullition, puis baissez le feu et laissez frémir 20 min à couvert. Remuez de temps en temps avec une cuillère en bois en raclant le fond, car les lentilles corail attachent volontiers. Quand elles sont complètement défaites, mixez au mixeur plongeant jusqu'à obtenir une texture lisse. Ajoutez le lait de coco, réchauffez sans faire bouillir, rectifiez le sel et terminez par le jus de citron vert hors du feu. Servez très chaud, avec un filet d'huile d'olive et quelques feuilles de coriandre si vous en avez.

Tarte aux pommes à la crème d'amande — pour 8 parts

Pour la pâte : 250 g de farine T55, 125 g de beurre froid en dés, 1 pincée de sel, 60 g de sucre glace, 1 œuf, 1 cuillerée à soupe d'eau glacée. Pour la crème d'amande : 100 g de beurre mou, 100 g de sucre, 100 g de poudre d'amande, 2 œufs, 1 cuillerée à soupe de rhum. Pour la garniture : 4 belles pommes acidulées, 20 g de beurre, 2 cuillerées à soupe de sucre roux, 3 cuillerées à soupe de confiture d'abricot.

Commencez par la pâte, la veille si vous le pouvez. Dans un saladier, mélangez la farine, le sel et le sucre glace. Ajoutez le beurre froid et travaillez-le du bout des doigts jusqu'à obtenir une texture sableuse, sans grumeaux de plus de 3 mm. Faites un puits, cassez-y l'œuf, ajoutez l'eau et rassemblez rapidement. Ne pétrissez surtout pas : dès que la pâte forme une boule, arrêtez-vous. Aplatissez-la en disque, filmez-la et mettez-la au réfrigérateur pour 1 h au minimum.

Préparez la crème d'amande. Fouettez le beurre mou avec le sucre jusqu'à ce que le mélange blanchisse, puis incorporez la poudre d'amande, les œufs un par un et le rhum. La crème doit être lisse et souple ; si elle a tranché, c'est que le beurre était trop froid — réchauffez le saladier quelques secondes au bain-marie et refouettez.

Préchauffez le four à 180 °C. Étalez la pâte sur ¾ de cm d'épaisseur et foncez un moule de 26 cm. Piquez le fond à la fourchette. Étalez la crème d'amande en couche régulière, sans aller jusqu'au bord : elle gonfle à la cuisson. Épluchez les pommes, coupez-les en quartiers puis en lamelles de ¼ de cm, et disposez-les en rosace en les faisant se chevaucher légèrement. Parsemez de beurre en petits morceaux et saupoudrez de sucre roux.

Enfournez 40 à 45 min. La tarte est cuite quand la crème est prise et que les pommes ont bruni sur les arêtes. Pendant qu'elle refroidit, faites tiédir la confiture d'abricot avec 1 cuillerée à soupe d'eau et passez-la au tamis, puis badigeonnez la surface au pinceau. Ce nappage n'a rien d'obligatoire, mais il donne à la tarte cet aspect brillant qu'on voit en vitrine.

Œufs cocotte aux champignons — pour 2 personnes

Ingrédients : 4 œufs très frais, 200 g de champignons de Paris, 1 échalote, 10 cl de crème épaisse, 1 noix de beurre, 1 brin de persil plat, sel, poivre, 1 pincée de muscade.

Préchauffez le four à 180 °C et faites chauffer de l'eau dans une bouilloire. Nettoyez les champignons avec un linge humide plutôt qu'à l'eau courante — ils absorbent tout ce qu'on leur donne, et un champignon gorgé d'eau ne dore jamais. Émincez-les finement. Hachez l'échalote.

Faites fondre le beurre dans une poêle. Ajoutez l'échalote, laissez-la devenir translucide pendant 2 min, puis montez le feu et versez les champignons. Ils vont d'abord rendre leur eau ; ne touchez à rien, attendez que le liquide se soit évaporé, et c'est seulement à ce moment-là qu'ils commenceront à colorer. Salez alors, poivrez, râpez un peu de muscade.

Beurrez deux ramequins. Répartissez les champignons au fond, ajoutez une cuillerée de crème dans chacun, puis cassez délicatement deux œufs par ramequin en veillant à ne pas crever les jaunes. Salez le blanc uniquement, jamais le jaune : le sel le marque de petits points blancs.

Disposez les ramequins dans un plat à bords hauts et versez de l'eau bouillante jusqu'à mi-hauteur. Enfournez 12 à 14 min. Le blanc doit être pris et le jaune encore coulant ; c'est une affaire de quelques dizaines de secondes, alors surveillez à partir de la 10e minute. Sortez, parsemez de persil ciselé et servez immédiatement, avec des mouillettes de pain grillé.

Blanquette de veau à l'ancienne — pour 6 personnes

Ingrédients : 1,2 kg d'épaule de veau en morceaux, 2 carottes, 1 poireau, 1 oignon piqué de 2 clous de girofle, 1 bouquet garni, 250 g de champignons, 200 g de petits oignons grelots, 50 g de beurre, 50 g de farine, 2 jaunes d'œufs, 15 cl de crème fraîche, 1 filet de jus de citron, gros sel, poivre en grains.

Mettez la viande dans une grande cocotte et couvrez d'eau froide. Portez lentement à ébullition et écumez avec soin pendant les 10 premières minutes : c'est cette étape, un peu fastidieuse, qui donne au bouillon sa limpidité. Ajoutez ensuite les carottes en tronçons, le poireau fendu, l'oignon clouté, le bouquet garni, une dizaine de grains de poivre et une bonne pincée de gros sel.

Laissez cuire à petits frémissements pendant 1 h 15. Le liquide ne doit jamais bouillir franchement, sinon la viande se durcit. Vérifiez la cuisson en piquant un morceau : la pointe du couteau doit entrer sans résistance et ressortir toute seule.

Pendant ce temps, faites revenir les grelots dans une noix de beurre avec 2 cuillerées d'eau et ½ cuillerée de sucre, à couvert, 10 min. Faites sauter les champignons à part, à feu vif, et arrosez-les d'un filet de citron pour qu'ils restent clairs.

Égouttez la viande en réservant le bouillon. Dans une casserole, faites fondre le beurre, ajoutez la farine et laissez cuire 2 min sans coloration en remuant sans arrêt. Versez petit à petit 80 cl de bouillon chaud filtré, en fouettant énergiquement pour éviter les grumeaux. Laissez épaissir 10 min à feu doux.

Hors du feu, délayez les jaunes d'œufs avec la crème dans un bol, ajoutez deux louches de sauce chaude en fouettant, puis reversez le tout dans la casserole. Ne faites plus bouillir à partir de cet instant : les jaunes coaguleraient et la sauce deviendrait granuleuse. Réunissez la viande, les champignons et les grelots dans la sauce, réchauffez doucement, rectifiez l'assaisonnement et ajoutez quelques gouttes de citron. Servez avec du riz long ou des pommes vapeur.

Un dernier conseil, valable pour toutes ces recettes : lisez-les en entier avant de commencer. C'est une évidence que tout le monde connaît et que presque personne n'applique, et c'est pourtant ce qui évite de découvrir à 19 h 45 qu'il fallait laisser reposer la pâte deux heures.
